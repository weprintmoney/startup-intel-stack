# 06 — Operational

The system's memory. Contents:

- `decision-log/` — dated entries (`YYYY-MM-DD-slug.md`) for every load-bearing decision: positioning, pricing, ICP changes, partnerships, strategy. Format: context, decision, why, impact. Agents and humans both read this before proposing changes to anything it covers.
- `processes/` — how recurring operations work (integration sync procedures, approval flows)
- `glossary.md` — team terms, product names, spellings agents must get right
