# Glossary

The names and terms agents must get **exactly right**, every time. Agents read this before writing anything customer-facing or committing docs. When an agent (or human) notices a recurring misspelling or naming drift, add a row here — this file is the fix, not a one-off correction.

## How to fill this in

1. **Product names:** exact casing and spacing of every product/offering (e.g., is it "AcmeAI", "Acme AI", or "ACME AI"? Pick one; record it).
2. **Names that get misspelled:** founders, key customers*, partners whose names have non-obvious spellings. Record the correct form and the wrong forms you've seen.
3. **Term definitions:** internal shorthand, category terms you use in a specific way, and terms you deliberately avoid.
4. **Retired terms:** phrases you used to use and have deliberately stopped (with a pointer to the decision-log entry that retired them).

*Customer names here only if this repo instance is private (it should be). Never copy this table into public content.
