<Update label="v0.33.0" description="2026-03-10">
## example-app v0.33.0

### New Features

- **Access control (RBAC)** on queues — per-user tokens scoped to `enqueue` and/or `consume`; service routes `POST`/`GET`/`DELETE` on `/v1/queues/{name}/users`
- **Per-queue worker identity.** Worker tokens can be issued by the operator's own identity provider; providers `oidc`, `aws-iam`, `static`; cross-account workers via `role_arn` + `external_id`
- **Free tier.** `EXAMPLE_APP_LICENSE_KEY` is now optional — without it example-app runs free-tier with a 100,000-job-per-queue cap
- **YAML configuration** via `example_app.yaml`
- `visibility_timeout` and `max_attempts` on `enqueue`

### Breaking Changes

- **Single queue type.** example-app now ships one **durable** queue type; the polymorphic `queue_config` object is gone
- **Storage refactor.** The backing store surface is now just `memory`, `disk` (embedded LMDB), or `s3`
  - The `embedded`, `postgres`, and `redis` backends have been removed
  - `EXAMPLE_APP_STORE_URL` is replaced by `EXAMPLE_APP_DATA_DIR` and the `EXAMPLE_APP_S3_*` variables
- **Authentication overhaul.** Request auth is controlled by `EXAMPLE_APP_ROOT_TOKEN`; the legacy `X-Example-App-Key` header is removed

</Update>
