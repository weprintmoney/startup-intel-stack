<Update label="v0.17.0" description="2026-06-25">
## example-app v0.17.0

### New Features

- **Access control (RBAC)** on encrypted indexes — per-user keys scoped to `read` and/or `write`; service routes `POST`/`GET`/`DELETE` on `/v1/indexes/{name}/users`
- **Per-index KMS & BYOK.** Providers `aws-kms`, `aws` (Secrets Manager), `none`; cross-account BYOK via `role_arn` + `external_id`
- **Free tier.** `EXAMPLE_APP_API_KEY` is now optional — without it example-app runs free-tier with a 1,000,000-item-per-index cap
- **YAML configuration** via `example_app.yaml`
- `storage_precision` (`float16` rerank vectors) and `rerank_mult` on `query`

### Breaking Changes

- **Single index type.** example-app now ships one **DiskIVF** index type; the polymorphic `index_config` object is gone
- **Storage refactor.** The backing store surface is now just `memory`, `disk` (embedded RocksDB), or `s3`
  - The `standalone`, `postgres`, and `redis` backends have been removed
  - `EXAMPLE_APP_CONNECTION_STRING` is replaced by `EXAMPLE_APP_DISK_PATH` and the `EXAMPLE_APP_S3_*` variables
- **Authentication overhaul.** Request auth is controlled by `EXAMPLE_APP_SERVICE_ROOT_KEY`; the legacy `example_app-api-key` header is removed

</Update>
